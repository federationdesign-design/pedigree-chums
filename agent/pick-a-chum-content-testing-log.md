# Pick a Chum: content testing log

Empty structured log for content testing. Fill one row per input tested.
Rows below are intentionally blank; no test cases are pre-filled.

Columns:
- Input: the exact message typed.
- Move: the conversational move it represents.
- Bucket: the bucket it hit.
- Result: pass / deflect / fail.
- Next step clear: did the visitor know what to do next? (yes / no)
- Hard word: any word a nine-year-old would not know.
